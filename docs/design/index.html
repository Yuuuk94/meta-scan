meta-scan 디자인 시스템

지금 packages/meta-scan-front에 실제로 반영돼 있는 토큰·컴포넌트 규칙입니다. 아키텍처 페이지와는 다른 주제입니다 — 그쪽은 저장소 구조/스택/구현 패턴 같은 기술 설계를 다루고, 이 페이지는 색상·타이포·다크모드 같은 UI/UX 디자인 시스템을 다룹니다.

현재 반영본 — "진 인덱스(Zine Index) + 오렌지" (ADR-008). 인쇄된 진단 보고서를 스캔한 듯한 편집/진(zine) 톤으로, 2026-08-19 meta-scan-front 전 화면에 실제로 퍼블리싱됐습니다(디자인 원본은 design/intake/zine-index-full/spec.md 인테이크 스펙, 소스 오브 트루스는 docs/design/design-system.md). 이전에 이 페이지가 기록하던 화이트/차콜+인디고 톤(ADR-004)은 2026-08-18 폐기됐습니다 — 아래 7. 이전 버전 절 참고.

1. 개요 CURRENT

SaaS 대시보드의 카드+그림자+둥근 모서리 문법을 의도적으로 피하고, 굵은 검정 룰(rule)과 채워진 색 블록으로 위계를 만드는 편집/진(zine) 톤입니다. 무료·고트래픽 애드센스 도구라는 제품 성격에 맞게 화려하지 않지만, 진단 결과(pass/warning/fail/info)가 실제 인쇄물의 도장· 색인 번호처럼 또렷하게 읽히는 걸 목표로 합니다.

밀도(Density)6 — Daily App Balanced체크리스트 항목이 많아 정보 밀도는 있지만, 굵은 룰 라인과 여백으로 숨 쉴 공간 확보
비대칭(Variance)5헤드라인·번호 라벨(01/02/03)에는 편집 레이아웃 특유의 비대칭, 체크리스트 카드 그리드는 스캔 결과 비교 목적상 균등 그리드 유지

3. 다크모드 배선 SYSTEM

@custom-variant dark (&:where([data-theme=dark], [data-theme=dark] *));

src/css/globals.css에 정의된 이 선언이 Tailwind v4의 dark: 변형을 OS prefers-color-scheme이 아니라 data-theme 속성에 매칭시킵니다.

  1. ToggleSetting.tsx에서 사용자가 테마를 토글하면 document.cookie의 theme 값을 갱신합니다(setDocumentCookies, utils/cookies.ts).
  2. 서버의 getSiteSetting()(utils/siteSetting.ts)이 이 쿠키를 읽어 app/[lang]/layout.tsx가 <html data-theme={theme}>를 렌더링합니다.
  3. data-theme 속성이 @custom-variant dark([data-theme=dark])와 매칭됩니다.
  4. 그 결과 globals.css의 :root[data-theme=dark] { ... } 토큰과 ui/**/*.tsx의 dark: 클래스가 동시에 반응해 렌더링됩니다.

쿠키를 쓰고 읽는 책임 분리(쓰기=클라이언트, 읽기=서버)는 아키텍처 페이지의 상태관리 패턴과 동일합니다 — 진 인덱스 개편에서도 바뀌지 않았습니다.

4. 사용 원칙 · 금지 목록 RULES

  • 브랜드 액센트는 하나(Signal Orange)뿐 — 상태 4색(pass/warn/fail/info)은 브랜드 액센트가 아니라 별도의 "판정 시맨틱 색"으로 관리합니다.
  • pass/warn/fail은 항상 동일한 무게의 채움 박스(2026-08-18 결정) — 배지 3종 중 하나만 채움 처리하고 나머지를 텍스트색으로만 표시하는 것 금지. info만 의도적으로 얇은 외곽선(낮은 무게).
  • 브랜드 액센트(오렌지)를 fail 배지 색으로 재사용 금지 — 브랜드와 "실패" 판정이 같은 색으로 겹치면 사용자가 오인합니다.
  • Sharp corners만 — 카드/버튼/입력 필드 어디에도 border-radius 사용 금지.
  • 그림자·글로우·그라디언트·glassmorphism 전면 금지 — backdrop-blur, shadow-*-500/20 같은 장식 효과 없음. 경계는 항상 하드라인 룰로.
  • 순수 검정(#000)·순수 회색 무채색 배경 금지 — 항상 웜톤 Ink/Paper 팔레트.
  • 이모지를 아이콘으로 사용 금지 — 필요하면 인라인 SVG(스트로크 기반), 없으면 텍스트/숫자 라벨로 대체.
  • 가짜 통계·조작된 숫자 금지 — ADR-004에서 이미 발견·제거한 패턴(예: 푸터의 "SCANS: 247,891"), 재발 금지.
  • 스크롤 유도 문구/화살표, "Elevate"·"Seamless"·"Next-Gen" 같은 AI 카피 클리셰 금지.

5. 컴포넌트 패턴 COMPONENTS

규칙은 design-system.md §4가 소스이고, 실제 구현은 Atomic Design 5계층(ui/atoms/ ui/molecules/ui/organisms)에 반영돼 있습니다. 각 프리미티브 파일 자체에 어떤 §를 따르는지 주석으로 명시돼 있어(예: ui/atoms/Rule.tsx가 §5, ui/molecules/StatusBadge.tsx가 §2/§8), 이 페이지와 소스 코드가 서로를 참조합니다.

규칙구현
버튼: 채움 사각형, sharp corners, 그림자 없음, 호버는 배경 톤 다운만ui/atoms/Button.tsx
배지(일반 태그/라벨): 채움 사각형, 자간 넓게(tracking-[.04em])ui/atoms/Badge.tsx
판정 배지(pass/warn/fail/info): Badge와 별도 프리미티브, 등가중 채움 + info만 아웃라인ui/molecules/StatusBadge.tsx
카드: 그림자 없이 1.5px solid 하드라인 테두리ui/molecules/Card.tsx
룰 라인(hairline/thick): 카드 그림자 대신 섹션/컬럼 구분에 사용ui/atoms/Rule.tsx
번호 라벨(01/02/03): Big Shoulders Display + 브랜드 액센트ui/atoms/NumberLabel.tsx
아코디언(FAQ): +/− 텍스트 토글, 애니메이션 없이 즉시 전환ui/molecules/Accordion.tsx

프리미티브 뼈대(cva variant → cn() 클래스 병합 → data-slot 속성 → named export)는 이전 인디고 버전(components/ui/*)에서 쓰던 것과 동일한 shadcn 골격이 그대로 유지됩니다 — 아키텍처 페이지의 "UI 프리미티브 골격" 참고. 바뀐 건 참조하는 토큰 값과 룰/하드라인 위주의 시각 언어입니다.

6. 판정 배지 시맨틱 PRODUCT-SPECIFIC

일반적인 디자인 시스템에는 없는, meta-scan 체크리스트 제품의 핵심 규칙입니다(checks[]의 pass/warning/fail/info — 점수 합산이 아니라는 ADR-005 결정과 직접 연결됩니다).

상태시각의미톤
pass채움 박스, #3E7D4F통과안심
warning채움 박스, #E3A61E경고 — 권장 사항 미충족주의, 겁주지 않음
fail채움 박스, #C81E3A실패 — 색인/크롤링에 실질적 영향명확한 문제
info얇은 외곽선만있으면 좋은 신호(AEO/GEO 계열 다수) — 없어도 감점 아님중립, 정보 제공

info가 시각적으로 가장 가벼운 이유: "없다고 감점"이 아니라 "있으면 좋은 신호"를 무료 진단 도구 톤에 맞게 사용자를 겁주지 않고 전달하기 위함입니다 (PRD 참고).

7. 이전 버전 (폐기됨) HISTORY

2026-08-13~08-18 사이 meta-scan-front에 실제 반영돼 있던 버전입니다 (ADR-004). 화이트/차콜 중립 배경 + 인디고 (#4f46e5) 단일 포인트 컬러, 점수/상태는 success/warning/destructive 3색 고정 매핑이었습니다 — 그 전(AI가 생성한 cyan→purple→pink 그라디언트, glow, 조작된 통계) 대비 크게 개선된 버전이었지만, 이후 체크리스트 결과 화면을 다시 설계하는 과정에서 이 톤 자체가 "AI 생성 SaaS 템플릿" 인상을 완전히 벗지 못했다고 판단해 ADR-008로 진 인덱스 톤에 전면 교체됐습니다.

ADR-004 (인디고, 폐기)
  • 화이트/차콜 중립 + 인디고 단일 포인트
  • 카드: 둥근 모서리 + 그림자(elevation) 기반 위계
  • 점수/상태: success/warning/destructive 3색
ADR-008 (진 인덱스, 현재)
  • 웜 페이퍼 화이트 + Ink + Signal Orange 단일 액센트
  • 카드: sharp corners + 하드라인 룰 기반 위계(그림자 없음)
  • 판정: pass/warn/fail/info 4색, 동일 무게 채움(info만 아웃라인)

인디고 버전 원문은 design.md (companion: colors.md/typography.md/ components.md) — 자체는 폐기됐지만 "그 이전(AI 그라디언트 테마)에서 무엇을 왜 고쳤는가"의 기록으로서는 여전히 유효합니다.
