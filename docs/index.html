meta-scan 문서 허브

저장소를 직접 스캔해 확인한 사실 기준으로 정리된 문서 모음입니다. 아래 카드 중 하나를 골라 들어가세요.

meta-scan은 URL 하나를 입력받아 메타 태그·robots.txt·sitemap·Lighthouse를 스캔해 보여주는 사이트 진단 서비스이며, Lighthouse가 다루지 않는 "AI 시대의 발견 가능성"도 항목별로 점검해 pass/warning/fail/info로 보여주는 SEO/AEO 체크리스트로 확장하는 중입니다 — 점수를 하나로 합산하지 않는, 수동적 진단 도구입니다(수익 모델은 Google 애드센스). 자세한 내용은 아래 PRD · 기획 카드에서 이어서 볼 수 있습니다.
