# 노출·유입 성장 계획

작성: 2026-11-11

## 현재 상태

- 구글 검색 노출 0, 애드센스 "가치가 별로 없는 콘텐츠"로 거절
- 기술 SEO(robots, sitemap, canonical, hreflang, meta)는 정상 (#64)
- 원인: 사람이 읽을 원본 글이 없음 (홈 본문 약 780자, 나머지는 도구 화면/약관), 외부 링크 0
- 애드센스 품질 기준과 구글 검색 품질 기준은 같다 → **콘텐츠를 쌓으면 둘 다 풀린다**

## 단계

### 1단계 — 애드센스 재심사 통과 (목표: 4주)

| 항목 | 완료 기준 |
|---|---|
| 사이트 블로그 | 한국어 글 15편 이상, 편당 2,500자 이상, 1차 출처 인용 |
| 소개 페이지 `/about` | 작성자(페르소나) + META_SCAN을 만든 이유 + 연락처 |
| 홈 보강 | "무엇을 검사하나요" 섹션, 최신 글 목록 |
| llms.txt | 실제 텍스트 파일 제공 (현재 soft 404) |
| 얇은 페이지 정리 | `/scan`, `/request-scan`, `/scan/:id` noindex + 사이트맵 제외 |
| 내비게이션 | 헤더/푸터에 블로그·소개 링크 |

완료 후 애드센스 재신청.

### 2단계 — 색인 (1단계와 병행)

- 서치콘솔·네이버 서치어드바이저: 사이트맵 제출, 글 발행마다 URL 검사 → 색인 요청
- 외부 링크: GitHub README, velog에 요약 + 원문 링크, GeekNews/OKKY 소개
- 측정: 서치콘솔 "색인된 페이지 수" 주 1회 기록

### 3단계 — 유입 확대

- 허브 글 7개 완성 (결과 화면 카드 단위)
- 용어사전 `/glossary/<term>`
- 플랫폼별 글 (카페24, 아임웹, 워드프레스…)
- 영어 번역 (반응 좋은 글부터)
- 측정: 서치콘솔 노출·클릭, GA4 블로그→스캔 전환
