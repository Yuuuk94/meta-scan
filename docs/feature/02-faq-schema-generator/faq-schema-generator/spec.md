# 기능 정의서 — FAQ 스키마 생성기

## 기능 개요
- 상태: 계획만 있음(스코프 제외) | 패키지: 미정 | PRD §10
- 의존성: ai-signals-checklist의 FAQ 섹션/구조화 데이터 감지 로직을 입력으로 재사용할 가능성 높음
- 체커가 "FAQ/PromptObject 신호 없음"을 진단하면, 스캔 대상 사이트의 실제 콘텐츠 기반으로
  `FAQPage` JSON-LD를 생성해 처방까지 이어주는 후속 제품.
