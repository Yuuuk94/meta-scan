# 기능 정의서 (확정) — 메인 페이지 FAQ

> `spec.md` 검토 완료. 백로그 갱신: 하단 CTA 버튼의 실제 목적을 정정(문의 버튼 아님) + 2개 항목 추가.

## 기능 개요
- 상태: 부분 구현 | 패키지: front
- 메인 페이지의 FAQ 아코디언(6개 질문) + 하단 "지금 스캔하기" CTA 버튼.
- **정정**: 이 CTA는 "문의" 버튼이 아니라 **다시 스캔을 시작하도록 유도하는 버튼**이다(카피가
  `faqCtaButton: "지금 스캔하기"` — 이전 초안에서 "문의 버튼"으로 잘못 추정했었음).

## 기능 요구사항

1. Given 사용자가 메인 페이지에 있음, When FAQ 항목을 클릭하면, Then 펼침/접힘된다
2. **(백로그, 미구현)** Given 사용자가 FAQ 하단 "지금 스캔하기" 버튼을 클릭, When 클릭이 발생하면,
   Then 페이지 최상단(Hero)으로 스크롤하고 URL 입력 필드에 포커스를 준다(현재 `onClick` 핸들러
   자체가 없음 — 버튼이 시각적으로만 존재하고 아무 동작도 안 함)
3. **(백로그, 미구현)** Given 사용자가 버튼 위에 마우스를 올림, When 호버하면, Then 마우스 포인터가
   활성화된다(`cursor: pointer`) — 확인해보니 공용 `ui/atoms/Button.tsx`에 `cursor-pointer` 클래스
   자체가 없음. 이 FAQ CTA만이 아니라 **사이트 전체 버튼에 영향**을 주는 공통 컴포넌트 이슈이므로,
   실제 구현 시엔 이 슬라이스가 아니라 `Button` atom 레벨(카테고리 3 공통 UI)에서 고치는 게 맞음.
