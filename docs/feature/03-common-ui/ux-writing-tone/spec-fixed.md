# 기능 정의서 (확정) — UX 라이팅 톤 통일 (한국어: 해라체 → 합니다체)

> 백로그로 신규 추가된 항목. 사용자 지적: 현재 한국어 카피가 "부자연스럽고 명령조"임.

## 기능 개요
- 상태: 미구현(백로그) | 패키지: front
- 한국어 사용자 대면 카피가 곳곳에서 **해라체/평서체("-다", "-라")**로 쓰여 있고, 일부는 실제
  **명령형**("URL을 확인하라", "다시 시도해 보라")이다. 전부 **합니다체(정중한 존댓말)**로
  통일한다. 영어 카피(`en.json`)는 이 문제가 해당하지 않음(영어에 한국어식 격식 단계 구분이
  없음) — 이번 백로그는 한국어 전용.

## 확인된 대상 (전수조사는 착수 시 필요, 아래는 발견한 예시)

- `dictionaries/ko.json`
  - `analyzingSubtext`: "…가져오는 중이다." → "…가져오는 중입니다."
  - `errorTitle`: "분석에 실패했다. URL을 확인하라." → "분석에 실패했습니다. URL을 확인해 주세요."
    (명령형 "확인하라"가 특히 두드러짐)
  - `faq2A`: "…이용할 수 있다." → "…이용할 수 있습니다."
  - `faq5A`/`faq6A`: "…걸린다.", "아니다. …처리된다." → 합니다체로
  - `faqCtaText`: "…점검해 보라." → "…점검해 보세요." (역시 명령형)
- 컴포넌트 내부 하드코딩 카피(다국어가 아직 `dictionaries`로 안 옮겨진 지점)
  - `app/[lang]/error.tsx`: `title: "문제가 발생했다"`, `description: "일시적인 오류일 수 있다.
    다시 시도해 보라."` → "문제가 발생했습니다", "일시적인 오류일 수 있습니다. 다시 시도해
    주세요."
  - `ui/organisms/BlockedScreen.tsx`는 issue #1에서 이미 dictionaries로 이관됨(아직 톤 자체는
    "-다"체 그대로 — 이 백로그의 대상에 포함)

## 기능 요구사항 (백로그, 상세 미확정)

1. Given 한국어 로케일의 사용자 대면 카피 전체, When 착수하면, Then `dictionaries/ko.json`과
   컴포넌트에 남아있는 하드코딩 한국어 카피를 전수조사해 해라체/명령형을 합니다체로 교체한다
2. 톤 가이드(합쇼체 기준, 존댓말이되 과도하게 격식적이지 않게)를 정하고 이후 신규 카피도 이 기준을
   따르도록 참고 문서화가 필요할 수 있음(이번 스코프에 포함할지는 착수 시 결정)

## 비고

- 정확한 대상 문자열 전체 목록은 이번 리뷰에서 표본만 확인함 — 실제 이슈로 등록해 착수할 때
  `dev-interview`가 전수조사(grep으로 "-다.", "-라." 종결 패턴 등) 후 범위를 확정해야 함
- 영어(`en.json`)는 스코프 아님
