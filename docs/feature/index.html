기능 인덱스 (Feature Index)

meta-scan이 가져야 할 기능 전체를 개발 진행 상태와 무관하게 수직 슬라이스 단위로 분류한 목록입니다. GitHub Issue로 등록하기 전 스펙의 원재료이며(docs/harness/tdd-issue-loop.md 참고), 마이그레이션·추가 개발 시 "지금 뭐가 있고 뭐가 없는지"를 확인하는 참고 자료이기도 합니다.

현재 상태: 23개 슬라이스 전부 spec.md 작성 + 검토(질문/답변 방식) 완료 — 확정본은 spec-fixed.md(아래 슬러그 링크가 가리키는 파일)이며, 검토 과정의 결정 로그도 함께 담겨 있습니다. GitHub Issue로 등록해 /tdd-issue-loop로 처리할 수 있는 상태입니다.

1. SEO/AEO/GEO 체커 이번 스코프

meta-scan의 핵심 제품 — URL을 스캔해 SEO/AEO 체크리스트(pass/warning/fail/info)를 보여주는 흐름 전체. PRD §2~§7 기준.

권장 순서: robots-gating → pipe-connection → 나머지 6개 체크리스트(서로 독립, content-stats-checklist만 basic-seo-checklist의 h1 판정을 흡수하므로 그 이후 권장) → lighthouse-suggestions. scan-result-shell은 별도 슬라이스로 두지 않고 pipe-connection에 흡수했습니다.

2. FAQ 스키마 생성기 스코프 제외

체커가 "FAQ/PromptObject 신호 없음"을 진단하면, 스캔 대상 사이트의 실제 콘텐츠 기반으로 FAQPage JSON-LD를 생성해 처방까지 이어주는 후속 제품. PRD §10.

슬러그설명상태
faq-schema-generator스캔 대상 사이트를 위한 FAQ 스키마 생성 도구계획만 있음

4. 메인/랜딩 페이지

기획·디자인·퍼블이 이미 끝난 섹션(재문서화 불필요)과, meta-scan 자기 자신의 SEO 기반(아직 비어있는 것으로 확인됨)으로 나뉩니다.

슬러그설명상태
process-explainer메인페이지 "작동 방식" 4단계 설명완료
faq-section메인페이지 FAQ 아코디언완료
site-seo-basicsmeta-scan 자체 sitemap.xml + robots.txt (Next.js 라우트 핸들러)미구현
site-faq-schemameta-scan 자체 FAQ 섹션에 FAQPage JSON-LD 추가미구현

site-faq-schema는 카테고리 2의 faq-schema-generator(스캔 대상 사이트를 위한 도구)와 다른 기능입니다 — 이쪽은 meta-scan 자기 자신의 FAQ 섹션에 스키마를 다는 것.

5. 수익화

PRD §8은 "이번 스코프의 구현 대상은 아니지만 레이아웃 설계 시 자리만 고려"라고 명시하는데, 최근 초안 메모엔 "이번 스코프"로 적혀 있어 상충됩니다 — 스코프 여부 확인 필요.
